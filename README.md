# Phoenix Rise

A mobile-first, cycle-optional women’s movement and wellbeing app prototype.

## Open the app

Open [index.html](./index.html) in a modern browser. The prototype is self-contained and has no build tools or external dependencies.

## Features

- Daily mood and energy check-ins, with optional symptoms and cycle day.
- Optional cycle tracking, with prototype data saved in the current browser’s local storage.
- Adaptable starter plans for strength, running, swimming and recovery.
- A guided breathing pause, affirmations and general wellbeing information.
- Topic-filtered community demo posts and locally saved new posts.
- Responsive navigation for desktop and mobile.

## Prototype limits

This is a front-end demonstration only. It does not include a server, database, sign-in, multi-user community, moderation service, health-device integration, clinical review workflow or production privacy controls. Data is stored only in the current browser and device. Avoid entering personal or sensitive information. Content is general wellbeing information, not diagnosis or treatment.

## Run locally

Download the repository and open `index.html`, or serve the folder with any static web server. GitHub Pages can also host this static prototype.
